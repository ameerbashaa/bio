# Marriage Biodata Docs

A VitePress + Vue site for hosting a marriage biodata page with animated sections and downloadable PDF content.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## GitHub Pages

The repository includes a GitHub Actions workflow in `.github/workflows/deploy.yml` that deploys the generated site to GitHub Pages.

1. Push this repository to GitHub.
2. Go to Settings > Pages.
3. Set the deployment source to GitHub Actions.
4. Push to the `main` branch to trigger deployment.
